# Supabase Auth Documentation

A technical writing portfolio project demonstrating professional API documentation for the [Supabase Auth](https://supabase.com/docs/guides/auth) library.

Built to Google Developer Style Guide standards using Docusaurus, GitHub, and Vercel.

## Writing standards applied

Every document in this project follows the [Google Developer Style Guide](https://developers.google.com/style):

- **Second person** — written directly to the reader ("you")
- **Active voice** — every sentence has a clear subject and action
- **Task-based headings** — headings start with a verb ("Create a project", not "Project creation")
- **Code before explanation** — code blocks appear before the prose that describes them
- **Tested code** — every code snippet was run and verified before publishing
